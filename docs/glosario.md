# Glosario

| Término | Definición |
|---|---|
| Cliente | Cliente final de Aguialarmas. Tiene una o varias cuentas. |
| Cuenta | Sucursal o sede física de un cliente, con ubicación y perímetro de llegada. |
| Zona | Área de la instalación de una cuenta (ej. Zona 2 · Bodega), asociada a su plano. |
| Ruta | Área de la ciudad dibujada en el mapa (antes "sector"). Cada cuenta pertenece a una. |
| Plantilla | Tipo de labor con prioridad, tiempo estimado, uso (técnico o supervisor) y capacidades requeridas. |
| Capacidad | Conocimiento técnico de un técnico (CCTV, alarmas, control de acceso…), con nivel. |
| OTG / OTC / OTO | Orden de trabajo general (creación), de campo y de oficina. |
| Marcación | Acción del técnico en la app en la que se toma el GPS (llegada, inicio, pausa, cierre…). |
| Bodega | Lugar donde está el inventario: principal, de dañados y una por cada cuenta. |
| Artículo recuperable | Se instala en una cuenta y puede volver a bodega (cámaras, sensores, paneles). |
| Artículo consumible | Se gasta al instalarse (chazos, tornillos, cinta). |
| Entrada por compra | Documento que ingresa mercancía a la bodega principal. |
| Solicitud de inventario | La hace solo el director técnico, ligada a una orden. |
| Traslado | Movimiento de la bodega principal a la bodega de la cuenta (la "salida"). |
| Reposición | Cambio de un equipo dañado: sale uno nuevo y el dañado queda pendiente por devolver. |
| Devolución | Sobrantes o equipos retirados que vuelven a bodega. |
| Nota de inventario | Alta o baja con motivo y aprobación del administrador. |
